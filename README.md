# DragonWeb 2.0 source code
This is DragonWeb's entire source code. By downloading the directory (index_files) and index.html, placing both files in a folder you can make your own DragonWeb and edit the code however you want. You're fully allowed to customize the code however you want. If you did edit it, you can share your idea by sending a screenshot or anything of your edited code by emailing matejmilanov1981@gmail.com (Gmail) or matejmilanov2014@outlook.com (Outlook). You can post your ideas on social media and do whatever you want. We don't care.
